# زُر العلا

## 1. ما هو المشروع؟

موقع عربي عن محافظة العلا. عنوان الصفحات في الهيدر: «زُر العلا». يعرض نصوصًا وصورًا عن المكان، وأماكن تراثية، وأنشطة، وفعاليات، ونموذج تخطيط رحلة، ومراجعات زوار. جزء من الموقع ملفات HTML ثابتة، وجزء يتصل بملفات PHP تحفظ في MySQL.

## 2. لماذا يوجد هذا المشروع؟

الصفحة الرئيسية تصف العلا بأنها جوهرة المملكة ومتحف طبيعي مفتوح، وتجمع أماكن تراثية ومراجعات. صفحة `plan.html` تجمع بيانات من يريد تخطيط رحلة. هذا ما يظهر من النصوص والملفات، دون وثيقة أهداف منفصلة.

## 3. من يستخدمه؟

| الطرف | ما يفعله في الملفات الحالية |
| --- | --- |
| زائر | يتصفح الصفحات، يرسل مراجعة، يحجز تذاكر فعالية، يرسل استفسار رحلة |
| مسؤول محتوى أو قاعدة | غير موجود كشاشة إدارة في الملفات الحالية |

لا حسابات مستخدمين ولا أدوار صلاحيات.

## 5. كيف يعمل النظام؟

1. الزائر يفتح صفحة HTML.
2. الصفحة تعرض النص والصور من `assets`.
3. عند المراجعة أو الحجز أو خطة الرحلة، JavaScript يرسل `FormData` بطلب `POST` أو يقرأ المراجعات بـ `GET`.
4. ملف PHP يقرأ `config.php` وينفّذ استعلام PDO.
5. MySQL يحفظ الصف أو يعيده.
6. الصفحة تعرض رسالة النجاح أو قائمة المراجعات.

```
المتصفح
  -> HTML + style.css + script.js
  -> api/*.php
  -> config.php
  -> MySQL
```

## 6. أمثلة واقعية

### إرسال مراجعة

1. في `index.html` قسم «مراجعات الزوار».
2. المتصفح يطلب `api/get_reviews.php` لعرض الموجود.
3. عند الإرسال يذهب `POST` إلى `api/add_review.php`.
4. يُدرج صف في جدول `reviews` (الاسم، النص، التقييم).
5. استنتاج من الكود: الصفحة تعيد جلب المراجعات بعد نجاح الإضافة لأن نفس الصفحة تستدعي `get_reviews.php`.

### حجز فعالية

1. من `events.html` يُرسل النموذج إلى `api/book_event.php`.
2. الحقول التي يتحقق منها الملف: عنوان الفعالية، الاسم، البريد، الجوال، عدد التذاكر.
3. الصف يُحفظ في `event_bookings`.

### خطة رحلة

1. `plan.html` يرسل إلى `api/add_inquiry.php`.
2. الحقول المطلوبة في PHP: `name` و `email` و `phone` و `dates` و `travelers`.
3. الاهتمامات إن وُجدت تُدمج بفاصلة في عمود `interests`.
4. الرسالة الاختيارية تذهب إلى `message`.
5. الصف يُحفظ في `trip_inquiries`.

## 7. رحلة المستخدم

لا تسجيل دخول.

1. فتح `index.html`.
2. الانتقال من القائمة إلى عن العلا، الأنشطة، الفعاليات، الأماكن، أو خطط رحلتك.
3. تعبئة مراجعة أو حجز أو استفسار.
4. PHP يحفظ في الجدول المقابل إذا كانت القاعدة متصلة بالاسم الذي يستخدمه `config.php`.
5. الزائر يرى نتيجة الطلب في الصفحة. لا توجد لوحة لاحقة لمراجعة الطلبات.

## 19. الخادم

PHP يقرأ `../config.php` من مجلد `api`. الاتصال:

- المضيف `localhost`
- القاعدة `alula_db`
- المستخدم `root`
- كلمة المرور فارغة في الملف
- الترميز `utf8mb4`
- `PDO::ATTR_EMULATE_PREPARES` مضبوط على `false`
- الاستعلامات في الملفات المقروءة تستخدم تحضير PDO

`config.php` عند فشل الاتصال يوقف التنفيذ برسالة تبدأ بـ «خطأ في الاتصال» ثم نص الاستثناء.

لا فئات خدمات منفصلة. كل ملف API سكربت مستقل.

## 20. مسار الطلب

مثال حقيقي: إضافة مراجعة.

```
المتصفح في index.html
  -> POST api/add_review.php
  -> require config.php
  -> INSERT في reviews
  -> JSON إلى المتصفح
  -> الصفحة تعرض النتيجة
```

مثال خطة الرحلة: `plan.html` ثم `POST api/add_inquiry.php` ثم `INSERT` في `trip_inquiries`.

## 24. الأمان

الموجود:

- تحقق من الحقول المطلوبة في `add_inquiry.php`.
- التحقق من صيغة البريد بـ `filter_var`.
- `travelers` يُحوَّل إلى عدد صحيح ويُرفض إن كان أقل من 1.
- استعلامات الإدخال المحضّرة في المسار المقروء.
- تقييم المراجعات مقيّد في SQL بين 1 و 5.

غير الموجود: تسجيل دخول، حد لمحاولات الإرسال، رمز CSRF، رؤوس أمان، إخفاء تفاصيل خطأ الاتصال (الرسالة تتضمن نص الاستثناء).

## 30. التثبيت

1. PHP مع PDO MySQL، وخادم ويب أو `php -S`، وMySQL.
2. أنشئ قاعدة باسم `alula_db` لأن هذا هو الاسم في `config.php`، ثم انقل إنشاء الجداول إليها. تنفيذ `create_database.sql` كما هو ينشئ اسمًا آخر: `u741730784_alualsys`.
3. عدّل مضيف القاعدة ومستخدمها إذا كان جهازك يختلف عن `localhost` و `root` وكلمة مرور فارغة.
4. ضع المجلد حيث يستطيع المتصفح فتح `index.html` عبر PHP حتى تعمل مسارات `api/`.
5. افتح `index.html` من عنوان الخادم لا كملف `file://` حتى يعمل `fetch`.

## 31. دليل التطوير

- صفحة جديدة: ملف HTML بنفس الهيدر والقائمة، وربطه بـ `style.css`.
- واجهة جديدة: ملف PHP داخل `api` يستدعي `../config.php` ويستخدم PDO.
- جدول جديد: أضفه في SQL وفي الاستعلام. لا مجلد migrations.
- صلاحية: لا بنية صلاحيات حالية لإضافة دور.

## 32. النشر
